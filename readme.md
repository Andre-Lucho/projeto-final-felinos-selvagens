# Projeto Felinos Selvagens

Projeto prático que serviu para encerramento do Módulo: FrontEnd com JavaScript e DOM.

Ele foi desenvolvido em apenas em **HTML, CSS e JavaScript Vanilla**, sem a utilização de nenhuma biblioteca JS - apenas o bundler Babel + Webpack (principalmente, pensando em compatibilidade com navegadores de versões antigas) e pequenas regras para avisos em erros estáticos com o linter ESLint.

Serviu como treinamento e aprimoramento de toda a parte teórica de JavaScript, CSS e HTML mas, principalmente, como aprimoramento de lógica de programação aplicada ao FrontEnd, integrando o DOM na contrução de um site.
A grande maioria das animações forma implementadas pensando na interação lógica da linguagem JS e DOM, e não na utilização de bibliotecas prontas de terceiros.
